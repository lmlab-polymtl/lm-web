This project develops methods for detecting inputs that differ from a model's training distribution. The goal is to assign confidence scores that help decide when predictions can be trusted and when inputs should be rejected as out-of-distribution.

The work targets reliable performance across deep neural network architectures, including transformer-based models, and connects OOD detection with adversarial robustness and deployed-system reliability.
